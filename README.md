# INC343: Computer-Based Control & Monitoring Systems

> This course introduces computer-based systems used for **control and monitoring of devices and machinery**. Students will gain both **theoretical knowledge** and **practical programming skills** through a progressive three-phase learning approach: **foundations** (TypeScript programming and control system basics), **web application development** (Next.js frontend and NestJS backend), and **system integration** (industrial communication protocols, IoT technologies, and data management). The course emphasizes **hands-on development** of **web-based monitoring and control applications** using **standard industrial communication protocols** for real-world industrial and automation environments.

## 🎯 Learning Outcomes

Upon successful completion of this course, students will be able to:

1. **Explain** the operation and architecture of computer-based **control and monitoring systems**.
2. **Develop computer programs** to control devices and machinery using **standard industrial communication protocols**.
3. **Design and implement web-based applications** that enable **control and monitoring of devices and machinery** through a web browser.

## 📈 Course Progression

This course is structured in **three progressive phases**:

### Phase 1: Foundations (Weeks 1–4)
- Introduction to control systems
- TypeScript programming fundamentals (self-study)
- Basic control logic and algorithms (self-study)
- **Assessment:** Quiz 1 (Week 5) – 20%

### Phase 2: Web Application Development (Weeks 5–7)
- Next.js frontend development
- NestJS backend development
- Full-stack integration and real-time communication
- **Assessment:** Quiz 2 (Week 8) – 25%

### Phase 3: System Integration (Weeks 9–12)
- Industrial communication protocols (Modbus, MQTT)
- IoT device integration
- Data management and visualization
- Complete system development
- **Assessment:** Quiz 3 (Week 13) – 35%

**Continuous Assessment:** Assignments throughout the semester – 20%

## 📖 Course Description

This course covers the principles and applications of **computer-based control and monitoring systems**. Topics include the **hardware and software components** used in monitoring and control, **software design and development for automation systems**, and **industrial standard communication protocols**. The course also explores **Internet of Things (IoT) technologies**, **web-based software development** for control and monitoring applications, **computer and embedded system data communication**, as well as **data management, analysis, and visualization**. Emphasis is placed on the development of **Internet-based monitoring and control applications** for real-world industrial and automation environments.
