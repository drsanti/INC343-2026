# Week 08: Quiz 2 – Full-Stack Web Application Development

This week is dedicated to **Quiz 2**, which evaluates your proficiency in developing full-stack web applications. The assessment content is primarily based on the **Frontend–Backend Integration** and **Real-Time Communication** topics covered in **Week 07**.

## Quiz Structure
The assessment is divided into two distinct parts:

### 1. Paper-Based (Theoretical & Hand-Written)
Focuses on understanding the architecture and logic behind web-based control systems:
- **Web Architectures**: Understanding the role of Frontend (Next.js) vs. Backend (NestJS).
- **RESTful API Design**: Principles of resource-based communication and JSON data exchange.
- **NestJS Fundamentals**: Knowledge of Modules, Controllers, Services, and Dependency Injection.
- **Real-Time Communication**: Principles of WebSockets and event-based updates.

### 2. Programming (Practical Implementation)
Requires building and integrating components across the stack:
- **Backend (NestJS)**: implementing RESTful controllers and WebSocket gateways for device status.
- **Frontend (Next.js)**: creating responsive dashboards using Tailwind CSS and React components.
- **Integration**: fetching data from APIs and handling live updates via WebSockets.

- [ ] **Review Week 05**: Next.js routing, Tailwind CSS, and React state management.
- [ ] **Review Week 06**: NestJS architecture, RESTful API implementation, and backend logic.
- [ ] **Review Week 07**: HTTP communication and real-time WebSocket integration.
- [ ] **Practice**: Build a simple "Device Control" dashboard from scratch.
