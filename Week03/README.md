# **Week 3: Programming Foundations and Control System Basics**

> Learning TypeScript programming fundamentals and core control system concepts to build the foundation for Quiz 1.

---

## 📖 **Week 3 Overview**

This week introduces **TypeScript programming fundamentals** and **core control system concepts**. You will learn how to write TypeScript code to represent control system components (sensors, actuators, controllers) and implement basic control logic. This week is crucial preparation for **Quiz 1**, which covers both theoretical knowledge and practical programming skills.

---

## 📚 **Learning Materials**

### **Reading Material**
**[Week 3 Reading Material](./Week03-Read.md)**

Topics covered:
* Role of programming in modern control systems
* TypeScript fundamentals for control applications (variables, data types, functions, classes)
* Control system components and their software representation (sensors, actuators, controllers)
* Open-loop and closed-loop control
* Feedback loops and system behavior
* Basic algorithms for control logic
* Data structures for control and monitoring
* Error handling and debugging in control software
* From control theory to software implementation

## 🎯 **Learning Objectives**

By the end of Week 3, you should be able to:

* Write TypeScript code with proper syntax, types, functions, and classes
* Represent control system components (sensors, actuators, controllers) in software
* Understand the difference between open-loop and closed-loop control
* Implement basic feedback loops and control algorithms
* Use appropriate data structures for control and monitoring applications
* Handle errors and debug control software
* Read and interpret simple TypeScript control programs
* Translate control system concepts into executable code
